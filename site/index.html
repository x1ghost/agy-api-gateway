一次请求如何流转

一个插件，沿用 Magpie 的能力
01 / CLIENT

Claude Code / DSH

发送消息、上下文和工具定义；执行自己的工具。

02 / MAGPIE

Magpie + 插件

管理接入、账号和会话；插件负责与 AGY 适配。

03 / OFFICIAL CLI

Antigravity CLI

使用已登录账号，按 ACP 会话发出模型请求。

04 / UPSTREAM

Google

接收由官方 CLI 发起的请求，返回模型结果。

01 · 会话与账号
Magpie 选择账号并传入会话标识；同一会话复用 ACP 会话，不同会话可以并发。客户端未提供会话 ID 时，Magpie 可能根据首条消息推导标识，相同首条消息可能发生碰撞。
02 · 模型请求
插件以本地代理替换载体请求的内容，官方 AGY CLI 使用自己的登录状态发起请求。
03 · 响应与标题
模型结果经 Magpie 返回客户端；AGY 的会话标题请求由 CLI 正常处理。

开始使用

需要 AGY 与 mitmdump

安装 provider

在 Magpie 中运行 magpie plugin add github:xhzq233/agy-api-gateway#fix/serialize-carrier-lifecycle 安装 PR 预览，然后选择已登录 AGY 的 HOME。

使用现有会话

会话标识来自 Magpie；插件不另建面向客户端的网关或账号池。

问题与贡献

遇到问题可在 GitHub 提 issue，也欢迎提交 pull request。
