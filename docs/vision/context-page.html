支持范围、验证与限制
项目当前行为边界
服务入口独立网关使用部署机器上的 AGY 登录，默认仅监听回环地址。跨机器连接需要 SSH 或其他安全通道；页面不连接模型或网关。
消息与工具支持文本、流式响应、客户端工具调用和结果回填。真实 AGY 工具调用及回填已通过；不能代表全部工具与故障场景。
模型使用量返回本次模型响应中的输入、输出和缓存命中 token。账号配额可通过命令读取快照或调用官方 AGY 刷新；快照有时间戳，不等同账单。
系统文本替换身份关键词；已知 CC 安全段默认换成 AGY 原生安全指令。用户消息、工具定义和结果不经过此过滤；安全覆盖及兼容性仍需验证。
保护与恢复转发预算、拒绝状态和响应日志持久化；相同幂等键可重放。上游错误或不确定中断会停止转发；不自动换号或伪造工具成功。
兼容范围支持 Messages 子集、部分图片与 adaptive thinking。不是完整 Anthropic API；精确 token 计数、文件、批处理等尚未实现。

这是静态说明，不表示实时健康或额度。实际功能取决于部署版本、客户端和官方 AGY 支持。
